# NeoConference

The next generation of virtual classrooms.

HD video, interactive whiteboard, breakout rooms, polls, and recording — built for educators.

Live at: https://neoconference.app

## Tech Stack

- Next.js 14 (App Router) + TypeScript + TailwindCSS
- - LiveKit Cloud (WebRTC SFU)
  - - Clerk (authentication)
    - - Prisma + PostgreSQL
      - - Vercel (hosting)
